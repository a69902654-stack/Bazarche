# Bazarche - Complete E-Commerce Platform

Project Description:
A comprehensive online marketplace built with PHP and MySQL, designed to deliver a modern shopping experience alongside robust management capabilities. The system is production-ready and includes all core functionalities required to launch and manage an e-commerce platform.

Key Features:

Complete Management System: Full CRUD operations for products and categories.

User Authentication: Secure registration and login system with role-based access control (Admin & Customer).

Dynamic Shopping Cart: Real-time cart updates for a seamless user experience.

Order Management: Complete workflow for order placement, processing, and tracking.

Product Reviews & Ratings: Allows customers to submit feedback and rate products.

Comprehensive Admin Dashboard: Centralized panel displaying key statistics, charts, and tools for managing users, products, and orders.

Responsive & RTL Support: Fully responsive frontend built with modern frameworks, including Right-to-Left (RTL) support for Persian language.

Database Security: All database interactions are handled via PDO prepared statements to prevent SQL injection, alongside secure password hashing.

Technical Stack:

Backend: PHP 7.4+ with Object-Oriented Programming (OOP) architecture.

Database: MySQL 5.7+ with a fully normalized schema and foreign key constraints.

Frontend: Tailwind CSS, Bootstrap 5, Responsive Web Design.

Security: Password hashing, Session management, Input sanitization.

User Roles:

Customers: Can browse products, manage the shopping cart and wishlist, place orders, and write reviews.

Administrators: Have full access to the admin dashboard for managing inventory, orders, users, and viewing analytics.

Database Structure:

Core Tables (8): users, products, categories, orders, order_items, cart, wishlist, reviews.

Integrity: Enforced data integrity through foreign key relationships.

Setup: Includes sample data for quick and easy project setup.

Project Status:
The project is complete and fully functional, covering all essential e-commerce features from the frontend user interface to the backend logic and admin panel. It is ready for deployment on any standard PHP/MySQL environment (e.g., XAMPP, WAMP, LAMP).
